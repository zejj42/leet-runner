# 283. Move Zeroes

<span class="badge easy">Easy</span> <span class="where">array · Beyond 75 · IX · Second Wind</span>

<https://leetcode.com/problems/move-zeroes/>

You get a list of integers, `nums`. Move every `0` in it to the end. The other elements keep the order they were in.

Do it **in place**, without building a copy of the list. Nothing is returned; the list itself is what gets judged.

**Example 1:**

> **Input:** `nums = [0,1,0,3,12]`  
> **Output:** `[1,3,12,0,0]`  

**Example 2:**

> **Input:** `nums = [0]`  
> **Output:** `[0]`  

**Constraints:**

 - `1 <= nums.length <= 10^4`
 - `-2^31 <= nums[i] <= 2^31 - 1`
