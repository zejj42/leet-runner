# 234. Palindrome Linked List

<span class="badge easy">Easy</span> <span class="where">linkedList · Beyond 75 · IX · Second Wind</span>

<https://leetcode.com/problems/palindrome-linked-list/>

`head` is the first node of a singly linked list. Return `true` *when its values read the same from front to back as from back to front (a **palindrome**)*, and `false` when they do not.

**Example 1:**

![](https://assets.leetcode.com/uploads/2021/03/03/pal1linked-list.jpg)

> **Input:** `head = [1,2,2,1]`  
> **Output:** `true`  

**Example 2:**

![](https://assets.leetcode.com/uploads/2021/03/03/pal2linked-list.jpg)

> **Input:** `head = [1,2]`  
> **Output:** `false`  

**Constraints:**

 - The list has between `1` and `10^5` nodes.
 - `0 <= Node.val <= 9`
