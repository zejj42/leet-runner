# 3. Longest Substring Without Repeating Characters

<span class="badge medium">Medium</span> <span class="where">string · First 75 · III · Stepping Up</span>

<https://leetcode.com/problems/longest-substring-without-repeating-characters/>

You get a string `s`. Find the length of the **longest** **substring** that has no duplicate characters.

**Example 1:**

> **Input:** `s = "abcabcbb"`  
> **Output:** `3`  
> **Explanation:** The substring "abc" has length 3. Note that "bca" and "cab" are also valid answers.  

**Example 2:**

> **Input:** `s = "bbbbb"`  
> **Output:** `1`  
> **Explanation:** The substring "b" has length 1.  

**Example 3:**

> **Input:** `s = "pwwkew"`  
> **Output:** `3`  
> **Explanation:** The substring "wke" has length 3.  
> Remember: the answer must be a substring, not a subsequence—"pwke" is a subsequence but not a substring.  

**Constraints:**

 - `0 <= s.length <= 10^5`
 - The string `s` contains English letters, digits, symbols, and spaces.
